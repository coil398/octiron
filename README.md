# Octiron

A small, from-scratch 2D game engine. Games are written in Rust, organized with
an ECS, rendered with [wgpu] (WebGPU, with a WebGL2 fallback), and—on the
web—compiled to WebAssembly. The same code targets native desktop via the same
[winit] event loop.

Octiron builds *on* the binding layer (wgpu / winit / [hecs] / [image]) but the
engine itself—loop, input, textured renderer, bitmap-font text, component
model—is its own.

## Games

Eight genres, all under [`examples/`](examples/), sharing one engine:

| Example | Genre | Shows off |
|---|---|---|
| [`demo`](examples/demo) | Pong | solid sprites, text HUD |
| [`invaders`](examples/invaders) | Space shooter | textured sprites, spawn/despawn, collisions, starfield |
| [`snake`](examples/snake) | Grid arcade | immediate-mode `Painter`, a sprite, restart flow |
| [`breakout`](examples/breakout) | Brick breaker | per-row tinted textures, lives/score, AABB bounces |
| [`flappy`](examples/flappy) | One-button | gravity, rising-edge input, stretched-texture pipes |
| [`platformer`](examples/platformer) | Scrolling platformer | **scene stack** (title/levels/win), **camera**, tile-grid physics, enemies |
| [`tetris`](examples/tetris) | Tetris | board model, 7 tetrominoes × 4 rotations + wall kicks, DAS, ghost, line clears, level gravity |
| [`survivor`](examples/survivor) | Arena roguelite | hundreds of ECS entities, 3 enemy types, auto-fire, XP gems, level-up upgrade choices, pause overlay, particles, difficulty ramp |

Art (sprites + the font atlas) is generated by [`tools/gen_assets.py`](tools/gen_assets.py).

## Quick start

```sh
./build.sh all          # build every example to web/pkg (add --release to optimize)
./serve.sh 8137         # serve web/ over HTTP
```

Open <http://localhost:8137> for the game menu, then click into any game (each
runs at `play.html?game=<id>`). Build a single example with `./build.sh invaders`.

## Engine API

A game implements [`Game`](engine/src/lib.rs):

```rust
use octiron::{run, Assets, Frame, Game, Painter, Sprite, Transform, Vec2, World};
use wasm_bindgen::prelude::*;

struct MyGame { tex: octiron::Texture }

impl Game for MyGame {
    // Runs once, after the GPU is ready: spawn entities, load textures.
    fn start(&mut self, world: &mut World, assets: &mut Assets) {
        self.tex = assets.load_png(include_bytes!("assets/hero.png"));
        world.spawn((
            Transform::new(Vec2::new(100.0, 100.0), Vec2::new(48.0, 48.0)),
            Sprite::texture(self.tex),         // or Sprite::color([r,g,b,a])
        ));
    }
    // Every frame: read frame.input / frame.dt, mutate the World.
    fn update(&mut self, world: &mut World, frame: &Frame) { let _ = (world, frame); }
    // Optional HUD on top, in immediate mode.
    fn draw(&mut self, _world: &World, painter: &mut Painter) {
        painter.text(16.0, 16.0, 0.6, [1.0; 4], "SCORE 0");
    }
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen(start)]
pub fn start() { run(MyGame { tex: octiron::Texture::WHITE }); }
```

- **Rendering** — any entity with a `Transform` + `Sprite` is drawn
  automatically; `Painter` adds immediate-mode rects, sprites, and bitmap-font
  text on top. Everything is one instanced, textured-quad pipeline (solid fills
  are a built-in 1×1 white texture, tinted).
- **ECS** — hecs, re-exported as `World` / `Entity`. `query_mut::<(&mut A, &B)>()`
  yields the component tuple; put `Entity` first to also get the id.
- **Coordinates** — a fixed logical resolution (800×600) stretched to fill the
  canvas, independent of device pixel ratio.

## Layout

| Path | What |
|---|---|
| `engine/` | the `octiron` crate (`renderer.rs`, `app.rs`, `painter.rs`, …) + `assets/font.png` |
| `examples/<game>/` | one game crate + its `assets/` |
| `web/` | landing menu (`index.html`) + player (`play.html`) + `thumbs/` + generated `pkg/` |
| `tools/gen_assets.py` | sprite + font-atlas generator (run with `uv run`) |
| `tools/shot.sh` | headless-browser screenshot harness |

## Verifying the render (headless)

`chrome-headless-shell` can't composite WebGPU, so screenshots use the full
Chromium under Xvfb:

```sh
./tools/shot.sh "http://localhost:8137/?game=invaders" tools/shot.png 3000
HOLD="ArrowRight,Space" ./tools/shot.sh "http://localhost:8137/?game=invaders"
TAP=Space ./tools/shot.sh "http://localhost:8137/?game=flappy"
```

One-time setup: `cd tools && npm install && npx playwright install chromium`.

## Requirements

- Rust with the `wasm32-unknown-unknown` target, and [`wasm-pack`](https://rustwasm.github.io/wasm-pack/)
- Python via [`uv`](https://docs.astral.sh/uv/) (asset generation), Node + Xvfb (screenshots), Python 3 (dev server)
