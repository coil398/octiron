# continent-sim アセット設計（徹底版）

地形 × 発展段階 × 状態 × 時代 × 文化 × 季節 の掛け算で数百〜千単位。全数手生成でなくモジュール化・オートタイル・パレットスワップ・スプライトシートで抑える。

## 0. 戦略
| 手法 | 内容 |
|---|---|
| ベース+オーバーレイ層 | 地形ベースに建物/畑/道/被災を別レイヤーで重ねる |
| オートタイル | 海岸線/河川/道/壁は 4bit(16)〜blob(47) 遷移セット |
| 文化パレットスワップ | 共通線画を文化ごとに再着色 |
| 時代モーフ | 石器→古代→中世→近代の数段だけ |
| スプライトシート | アニメはフレーム横並び1枚（要エンジンのアニメヘルパー） |

## 1. マップタイル
- 地形ベース: 9地形 × 季節{標準/雪/秋/春/乾季}、森=針葉/広葉/熱帯、草原=短草/長草/花
- 発展段階(最重要): 農=開墾→畝→播種→生育→実り→収穫後→休耕/段々畑/果樹園/葡萄畑/牧草地。居=焚火跡→小屋→集落→村→町→都市→大都市。採掘=鉱山/採石場/製材所/塩田/漁場/馬牧場
- インフラ(オートタイル): 道(土/石畳/十字/分岐)/橋/市壁/門/塔/港/灌漑/堤防/運河
- 状態: 焼け跡/火山/洪水/干ばつ亀裂/疫病荒廃/戦災/放棄/雪冠/海岸/河川曲がり
- 遷移: 海↔陸(8方向+角)/深海↔浅瀬/河川(直線/曲/合流/河口/水源)

## 2. オブジェクト/建造物(時代×文化×状態)
| 分類 | 例 |
|---|---|
| 住居 | 竪穴/テント→丸太小屋→町家→邸宅/塔→近代家屋 |
| 生産 | 農家/風車/水車/鍛冶/鉱山櫓/倉庫/市場/灯台/隊商宿 |
| 公共 | 穀倉/神殿/祠/教会/モスク/役所/図書館/記念碑/像 |
| 軍事 | 柵→石壁/門/物見櫓/砦/城/兵舎/攻城陣 |
| 特別 | 首都/遺跡/各文明ワンダー |
状態: 建設中(足場)→完成→損傷→廃墟、煙/夜灯り(アニメ)。文化×時代は全焼きせずパレットスワップ+装飾オーバーレイ+時代3〜5段。

## 3. キャラ/動物(透過)
人間(役割×時代×文化): 部族民/農夫/牧夫/漁師/兵(槍剣弓騎兵銃)/水夫/商人/貴族/君主/聖職者/学者/建設者/遊牧民。動物: 野生(鹿猪狼熊鳥魚鯨)/家畜(牛羊馬豚山羊鶏)/駄獣(馬車/牛鋤)。

## 4. アニメーション(スプライトシート)
| 対象 | 状態 |
|---|---|
| 地形 | 水きらめき/波/草麦の風/煙/炎/滝/旗 |
| 建物 | 建設/煙/夜灯り/水車風車回転/損傷 |
| キャラ/動物 | 待機/歩行/労働/戦闘/死亡 |
| イベント | 爆発/洪水波/疫病/建国/会戦/収穫 |
| 環境 | 季節遷移/昼夜/天候 |
各=横並びフレーム1シート。要エンジンのアニメヘルパー(未実装)。

## 5. 生成パイプライン(Codex復帰後)
1タイル/エージェント+実ファイル目視検証(並列15で~10成功の教訓→逐次/リトライ)。アニメはNフレーム横並び1枚指定→deai→シートatlas。文化差はパレットスワップ。透過は deai.py --chroma。オートタイルは遷移セット→4bit/blobでサブ矩形選択。
